# FamilyTree

Backend-логика для работы с семейным древом.

Проект предназначен для хранения людей, их родственных связей и построения иерархического представления семейного древа.

⚠️ Ветка `dev` содержит активную разработку и может быть нестабильной.

---

## Описание

FamilyTree — это backend-проект, реализующий бизнес-логику генеалогического древа:

- создание и обновление людей
- связывание людей через родителей
- получение родственников
- построение иерархического дерева

Проект фокусируется на корректности бизнес-логики и работе с древовидными структурами данных.

---

## Архитектура

Проект разделён на логические слои:

- **Services**  
  Содержат бизнес-логику, проверки и алгоритмы построения родственных связей.

- **Repositories**  
  Отвечают за доступ к данным и SQL-запросы.

- **DTO**  
  Используются для передачи данных между слоями.

- **Mappers**  
  Преобразуют доменные модели в DTO.

---

## Родственные связи

Связи между людьми формируются через родителей:

- мать
- отец

На их основе реализованы методы получения:

- родителей
- детей
- предков
- потомков

Для предков и потомков поддерживается ограничение глубины поиска.

---

## Построение дерева

Для получения иерархического представления используется структура:
PersonTreeNodeDTO
├── Person
├── Parents
└── Children

Дерево строится рекурсивно:
- с контролем глубины
- с защитой от циклов через список посещённых идентификаторов

---

## Валидация

В проекте используется двухуровневая валидация:

- **FluentValidation** — проверка входящих DTO
- **Сервисная валидация** — бизнес-правила и проверки, требующие доступа к данным
